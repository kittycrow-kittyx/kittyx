# Target contracts

`ThistleMachine` identifies thistle32 or thistle64. `ThistleInstructionSet` selects thistle or rv64gc. `THISTLE32` defines the 32-bit word size and version 1 container. `THISTLE64` defines 64-bit words, version 2, RV64GC and the LP64D ABI. These constants take no runtime input and do not modify state.
