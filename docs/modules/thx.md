# Binary format identities

`THISTLE_OBJECT_MAGIC` contains THO1 and THO2. `THISTLE_EXECUTABLE_MAGIC` contains THX1 and THX2. `THISTLE_EXECUTABLE_EXTENSIONS` lists .thx and .39. `ThxEnvelope` describes magic, metadata and payload lengths in bytes, and checksum. The declarations do not parse or validate binary data.
